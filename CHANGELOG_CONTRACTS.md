## 2026-10-13 — v26: этап 5.1 — по ревью выдачи e2e 5.0.4
- HTTP `ResultItemSummary.evidence_kind`: `market` | `research` | `patent` — на чём держится сигнал. Ранние
  исследования — тоже слабые сигналы: это пометка, а не фильтр. Поле добавлено, прежние клиенты его игнорируют.
- analyzer:
  - порог кластеризации подбирается для коллекции (квантиль расстояний до ближайшего соседа);
  - предварительная оценка моделью идёт по всем кластерам, кандидаты — лучшие по ней;
  - правило «слабо связан с запросом» помечает только выбросы;
  - новое правило «известная зрелая область» (решение MATURE, причина MATURITY_LEXICON).
- orchestrator:
  - уверенность карточки с одним независимым источником — не выше средней;
  - задание с меньшим числом карточек, чем запрошено, при полном прохождении этапов — COMPLETED;
  - источник, отключённый настройкой или без ключа, не считается отказом сбора.
- collector:
  - список `low_quality_domains` в trust_rules (доверенность LOW);
  - GDELT выключен по умолчанию (`WS_SOURCE_ENABLED_OVERRIDE=gdelt=false`).
- Быстрый замер `--e2e`:
  - сохраняет карточки (`*_cards.jsonl`, `*_cards.csv` для разметки);
  - распределение стадии и тренда и оснований;
  - `--verdicts` и `--score-cards` — доля слабых сигналов по ручной разметке.
- `ml/data/benchmark/card_verdicts_e2e501.csv` — разметка 151 карточки ревью e2e 5.0.4.
