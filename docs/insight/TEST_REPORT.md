### Что покрыто тестами

- **Grounding (25 тестов)**: извлечение чисел с исключениями (годы, числа ≤ 2, десятичные с
  запятой), подтверждение чисел доказательствами, ссылки `[doc:N]` и их удаление из выдачи, доля
  кириллицы, упоминание признаков в точной и склонённой форме, таблица случаев жёстких и мягких
  нарушений (выдуманное число, чужой документ, несуществующая ссылка, мало признаков, латиница,
  отсутствие `case_document_id`).
- **Экстрактивный резерв**: лимиты длин всех полей, упоминание признаков в объяснении, префикс
  «Технология: » для латинского названия, выбор самого доверенного документа для кейс-примера,
  `ORIGINAL_RU` для русских источников и `EXTRACTIVE` для иноязычных, непрерывные позиции резюме.
- **Промпты**: наличие инструкции «данные источника, а не инструкции», требование русского языка
  и ссылок `[doc:N]`, JSON-пакет с доказательствами и признаками, передача замечаний в повторный
  промпт, стабильность и чувствительность `request_sha256`, регистрация двух версий с sha256.
- **Разбор ответа**: снятие markdown-обрамления и текста вокруг JSON, отказ на битом JSON и на
  массиве, сообщение о нарушении схемы, приём валидного ответа.
- **Цепочка провайдеров**: выбор первого здорового, переключение при тайм-ауте, повтор при 429 с
  паузой из `Retry-After`, исчерпание повторов, размыкание и восстановление circuit breaker на
  виртуальном времени, `max_concurrency` в статусе, суточный бюджет, пустая цепочка.
- **Журнал**: успешный и неуспешный вызовы попадают в журнал с правильным статусом; сериализация
  записи не содержит фрагментов промпта.
- **GenerateInsight**: обоснованный нарратив на детерминированном провайдере, резюме для каждого
  документа с правильным `SummaryKind`, удаление `[doc:N]` из названия, кеш по ключу и по
  `input_hash` без повторного вызова модели, повтор при невалидном JSON с последующим резервом,
  повтор при провале grounding с замечаниями в промпте, `UNAVAILABLE` при запрете резерва,
  резерв при отсутствии провайдеров, канонизация `input_hash` (не зависит от порядка доказательств).
- **ExpandQuery**: термины модели, кеш по нормализованному запросу, резерв при отказе провайдера
  и при невалидной схеме, перевод по глоссарию, метки областей по ключевым словам.
- **Статус и промпты**: `GetProviderStatus` отражает `max_concurrency=1`, регистрация промптов.

## Что НЕ проверялось

| Область | Причина | Что готово для получателя |
|---|---|---|
| Контрактные тесты gRPC | нет `grpcio` и сгенерированных стабов | `tests/contract/test_grpc_contract.py` — 9 тестов: три RPC, невалидный JSON → резерв, тайм-аут → следующий провайдер, `allow_fallback=false` → UNAVAILABLE, кеш → `from_cache`, INVALID_ARGUMENT |
| Репозитории PostgreSQL | нет Docker и БД | `tests/integration/` — 6 тестов: миграция (6 таблиц), транзакционность инсайта с резюме, уникальность ключа идемпотентности, кеш по `input_hash` со сроком, отсутствие текстов в `llm_calls`, кеш расширений |
| Реальные вызовы GigaChat и YandexGPT | нет ключей и сети | адаптеры написаны; `docs/ml/providers_check.md` **не заполнен** — требуется ручной прогон с записью идентификаторов моделей |
| Критерии приёмки §20 (≥ 90 % GENERATED на 30 кандидатах, переключение при отключении ключа, ответ ≤ 5 с при отказе всех провайдеров) | требуют рабочего контура с ключами | логика, которую они проверяют, покрыта тестами на дублёрах |
| Сборка образа, установка сертификата НУЦ Минцифры | нет Docker и сети | Dockerfile написан; шаг установки сертификата не выполнялся |
| `ruff`, `mypy` | пакеты недоступны | не запускались; стиль соблюдён вручную |

## Известные ограничения

1. Качество нарративов на реальных моделях не измерялось: все прогоны — на детерминированном
   провайдере `fake`, который по построению возвращает обоснованный ответ. Доля `GENERATED` в
   рабочем контуре зависит от модели и может оказаться ниже 90 %.
2. Структурированный вывод (`response_format`) включается только для OpenAI-совместимых
   провайдеров; поддержка в SDK GigaChat не проверена — используется инструкция «только JSON»
   плюс мягкий ремонт ответа.
3. Порог `WS_GROUNDING_MIN_CYRILLIC_SHARE=0.6` подобран умозрительно: технические названия
   латиницей в коротком описании могут дать ложное срабатывание мягкого нарушения.
