# Спецификация интерфейса для разработки — UI 1.3.0

Документ описывает экраны после доработки UX/UI: что пользователь видит, из каких токенов и
компонентов это собрано, как ведёт себя на разных размерах и в каких состояниях бывает. Код уже
реализован в `services/ui`; спецификация нужна, чтобы при следующих правках не потерять решения.
Причины решений — в `docs/ui/DECISIONS.md` (D-U8…D-U17).

## 1. Общее

### Режимы раскладки

| Режим | Условие | Что меняется |
|---|---|---|
| Телефон | ширина < 640 px | навигация — нижнее меню, шапка — логотип, индикатор API и пауза; страница листается целиком |
| Документ | 640–1023 px или высота < 600 px | навигация сверху, страница листается целиком |
| Приложение | ≥ 1024 × 600 px | слева боковая панель (14rem, на 1024–1279 px — 6rem), страница без общей прокрутки, длинные колонки листаются внутри |

Блоки внутри страницы перестраиваются по ширине своей области (`@container`), а не окна:
`view` — область страницы, `excluded`, `detail`, `stats`, `predictors`, `scope` — свои контейнеры.

### Размер шрифта

`html { font-size: 93.75% }` — 15 px при стандартных 16 px браузера. В режиме приложения
`clamp(0.875rem, min(calc(0.53125rem + 0.44vw), calc(0.375rem + 1.25vh)), 1.1875rem)` — 14–19 px
по размеру окна. Все размеры в rem, поэтому настройка «крупный шрифт» браузера масштабирует весь
интерфейс. Вторичный текст — `max(13px, …)`; исключение — подписи нижнего меню и узкой панели (12 px).

| `--paper` / `--paper-2` / `--paper-3` | #fff / #f8f6fb / #f3f0f8 | #170f20 / #1c1327 / #22182e | карточки, подложки, нейтральные метки |
| `--line` / `--line-2` | #e4dfeb / #d3cbdf | #2c2138 / #3b2d4a | рамки, разделители |
| `--brand-fill` / `--brand-ink` | #4a086c / #4a086c | #7b2cae / #c9a2ee | главные кнопки, выбранный фильтр / ссылки |
| `--violet` | #7a2ba6 | #b78bff | полоса сводок, индекс ниже 75 % |
| `--signal` / `--signal-ink` | #0e9fb6 / **#066c7d** | #3fd6ea / #5fe0f0 | «слабый сигнал», вклад «за», процесс выполнения |
| `--mature` / `--mature-ink` | #c67a12 / #955a06 | #f0a948 / #f3b866 | «зрелость», вклад «против», «частично» |

| `--danger-ink` | #a32640 | #ff8a9c | ошибки |
| `--radius` / `--radius-lg` | 0.85rem / 1.2rem | | карточки / панели |

| `--font-display` | Jura | | заголовки страниц, числа |

**Смысл цвета.** Бирюзовый — «слабый сигнал» и «идёт выполнение»; янтарный — «зрелость» и
«частично»; зелёный — только высокий уровень и «Завершено»; фиолетовый — бренд, навигация,
главные кнопки. Средний и низкий уровни — нейтральные.

**Метки уровней** (`chip--level-1/2/3`, уверенность модели и доверенность источника одинаково):

| Уровень | Вид | Шкала |
|---|---|---|
| 3 — высокий | зелёная метка (`--ok-soft`, `--ok-ink`) | три деления закрашены |
| 2 — средний | нейтральная (`--paper-3`, `--ink-2`, рамка `--line-2`) | два деления |
| 1 — низкий | прозрачная, пунктирная рамка `--line-2`, текст `--ink-3` | одно деление |

Шкала — `::before` 0.75 × 0.7rem из трёх столбиков 3 px (45 %, 72 %, 100 % высоты); незакрашенные —
`currentColor` 22 %. Уровень читается без цвета.

**Панели-сводки** (`.stats`, `.gauges`, `.insight__card`, `.method__block--steps`): в светлой теме —
`--paper`, рамка `--line`, сверху полоса 3 px `--violet`, тень `--shadow-1`; в тёмной — подложка
прибора `--scope-surface`, рамка `--scope-line`. Тёмным в обеих темах остаётся только прибор с
полем сигналов (`.scope`).

## 2. Результаты `/results/:jobId`

### Раскладка

Порядок в разметке: шапка → выдача (вкладки) → сводка. На узком экране так и показывается:
список сигналов на первом экране, сводка ниже. В режиме приложения при ширине области от 64rem —
сетка `"head head" / "body run"`, правая колонка `clamp(16.5rem, 25cqi, 26rem)`.

| Элемент | Состав | Примечание |
|---|---|---|
| Шапка | «Поисковый запрос», запрос (Jura, до 4 строк, в приложении — 2), статус, строка фактов, «Новый запрос», «Отменить задание» | строка фактов: дата · длительность · N в выдаче · M кандидатов, `--ink-3`, 13 px |
| Полоса хода | этап, подсказка, прогресс | только пока задание не завершено; плашка статуса в шапке в это время скрыта |
| Вкладки | «Найденные слабые сигналы N», «Исключённые кандидаты M» | на телефоне — сегменты на всю ширину, подписи «Сигналы» и «Исключённые» |
| Список | строки сигналов | при ширине области ≥ 40rem — список и карточка рядом (0.92fr / 1.28fr), иначе карточка раскрывается в строке |
| Сводка | 4 показателя, спектр, «Ход задания» | показатели в 2 колонки, при ширине ≥ 44rem — в 4 |

### Строка сигнала (`.signal-row`)

Сетка `2.3rem | 1fr | auto`, области `rank title score / rank orig orig / rank bar bar / rank meta meta`
(в режиме списка добавляется `chev`). Отступы 0.6rem 0.85rem 0.65rem 0.55rem, промежутки 0.3rem 0.7rem.

| Часть | Правило |
|---|---|
| Название | русская часть `title_ru`, Lato 700, до 2 строк (на телефоне 3), обрезка многоточием |
| Оригинал | текст в скобках из `title_ru`, если в нём латиница: `--ink-3`, 13 px, 1 строка, `lang="en"` |
| Индекс | `percent(score)`, Jura |
| Полоса | заливка до значения, отметка 75 %; ≥ 75 % — бирюзовая, ниже — фиолетовая |
| Метки строки | уровень уверенности (цвет по таблице уровней), «инсайт экстрактивный» — только если нарратив не `GENERATED` (`--mature-ink`), «источников: N», основа (рынок, исследование, патент) |

### Карточка сигнала (`.detail`)

| Часть | Правило |
|---|---|
| Шапка | «Ранг N из M», название (Lato 700, 1.3rem), оригинал (2 строки), справа кнопка «Открыть инсайт» (`btn--primary`) |
| Закрепление | в режиме «рядом» шапка липнет к верху карточки при прокрутке (фон `--paper`, нижняя рамка) |
| Шкала | круговая, подпись «индекс уверенности» и значок «i»: пояснение во всплывающей подсказке и скрытым текстом для диктора |
| Предикторы | до 5 признаков; `sc_*` — «протот…», полная подпись в `title`; у остальных пояснения в скобках уходят в `title` |
| Объяснение | текст из бэкенда как есть |

При ширине карточки ≥ 46rem — две колонки: шкала и метки слева (12–15rem), признаки и объяснение справа.

### Сводка (`StatsRow`)

| Показатель | Значение | Подсказка |
|---|---|---|
| Кандидатов на слабый сигнал | `candidates_found` | «признаны: `weak_signals_total`, в выдаче после проверки: N» + «Показать исключённых» |
| Обработано источников | `sources_processed` | «`http_requests_total` запросов, `documents_collected` документов» |
| Уверенность модели выше 75 % | `weak_signals_confident` | «среди найденных слабых сигналов» |
| Версия модели | `model_version_id` | число экстрактивных инсайтов или «Все инсайты сгенерированы моделью» |

Спектр «Индекс уверенности по рангу»: столбик на сигнал, пунктир 75 %; щелчок по столбику выбирает
сигнал (это быстрый путь мышью, с клавиатуры столбики пропускаются — тот же выбор есть в списке).

### Исключённые кандидаты (`ExcludedPanel`)

| Часть | Правило |
|---|---|
| Вступление | одно предложение, `--ink-2` |
| Фильтр | «Все N» и по одному фильтру на решение, которое встречается: не по теме → зрелая → хайп → мало доказательств; `aria-pressed`, выбранный — `--brand-fill`, белый текст |
| Строка | кнопка с `aria-expanded`: название (Lato 700; латинское — `lang="en"`), плашка решения, причина, «Скоринг: N %» (слово скрыто, для диктора), «N док.», шеврон |
| Раскрытие | под строкой — объяснение решения, фон `--paper-2` |
| Сетка строки | `1fr auto minmax(9rem,13rem) 3.6rem 4.6rem 1.1rem`; при ширине области ≤ 44rem — три ряда: название / решение, скоринг, документы / причина |

В режиме приложения список листается внутри вкладки.

### Состояния страницы

| Состояние | Что видно |
|---|---|
| Загрузка задания | скелетон из 4 строк |
| Задание ещё собирает данные | вместо списка — прибор «скан» и текст «Выдача появится…»; вкладка исключённых неактивна |
| Формирование инсайтов | сигналы появляются по мере готовности, опрос каждые 3 с |
| Завершено без сигналов | «Слабые сигналы не найдены», причины — во вкладке исключённых, кнопка «Показать исключённых» |
| Завершено с ошибкой до выдачи | «Выдача не сформирована» с текстом ошибки и «Новый запрос» |
| Частичный результат | баннер «Результат неполный» со списком причин (в сводке) |
| Задание недоступно | баннер ошибки |

## 3. Инсайт `/insight/:itemId`

### Раскладка

Сверху вниз: панель действий («К списку сигналов», «Экспорт») → шапка-карточка → полоса разделов →
разделы документа. При ширине области ≥ 62rem шапка делится на две колонки: название слева,
индекс, метки и факты справа (до 34rem). При ширине ≥ 70rem «Источники» — колонкой справа
`clamp(22rem, 32cqi, 32rem)`, она липнет под полосой разделов и листается сама.

| Часть | Правило |
|---|---|
| Контекст | «Запрос: …»; «Исходное название кандидата» — только если оригинал не показан под названием |
| Название | русская часть, Lato 700, `clamp(1.25rem, 0.85rem + 0.6cqi, 1.55rem)`; оригинал строкой ниже, `lang="en"` |
| Метки | «Слабый сигнал, ранг N», уровень уверенности; статус нарратива — только если не `GENERATED` |
| Факты | «Стадия», «Тренд упоминаний» — подписанными значениями в две колонки |
| Полоса разделов | 7 коротких подписей: Описание, Преимущество, Кейс, Оценки, Почему сигнал, Источники N, Происхождение; полное название раздела — в `title`; липнет сверху; активный раздел — `--brand-soft`; на узком экране листается вбок |
| Текст разделов | служебные ссылки модели «(документ d5)», «[doc:2]» удаляются (`cleanRefs`) |
| Оценки | резюме — 2 строки, полный текст — в карточке источника по ссылке |
| Источники | заголовок `h3` с `lang` из `language_code`; метки: тип, доверенность (уровни), язык, дата; «Фрагмент оригинала» свёрнут |

### Меню «Экспорт»

| Действие | Поведение |
|---|---|
| Открытие | щелчок или Enter/пробел на «Экспорт»; список 17rem под кнопкой справа |
| «Печать или PDF» | закрывает меню и вызывает печать браузера |
| «Markdown (.md)» | закрывает меню и скачивает `insight-<ранг>-<транслит названия>.md` |
| Закрытие | Escape (фокус возвращается на «Экспорт»), щелчок вне меню |

### Печать

Печатается только документ: без навигации, панели действий, полосы разделов, кнопок и
свёрнутых фрагментов; тёмный текст на белом в обеих темах; после названия источника — адрес
ссылки; разделы и карточки не разрываются между страницами; поля 14 × 12 мм, базовый размер 11 pt.

## 4. Запрос `/search`

| Часть | Правило |
|---|---|
| Поле | `textarea`, 4 строки, 16 px и больше (иначе iOS увеличивает страницу), счётчик «N / 500 символов» |
| Подсказка клавиш | «⌘ + Enter» на macOS и iOS, иначе «Ctrl + Enter»; на телефоне скрыта |
| Примеры | 4 кнопки; на телефоне — одной лентой, листается вбок |
| Размер выдачи | группа радиокнопок ТОП-5, 10, 15, 25, 50 (по умолчанию 15); выбранная — белая с рамкой `--brand-line`; на телефоне — 5 равных сегментов |
| «Найти слабые сигналы» | всегда активна; во время отправки — «Отправляем…» и недоступна |
| Ошибка ввода | меньше 2 символов: красная рамка поля, `aria-invalid`, текст под кнопкой «Опишите направление хотя бы двумя символами, например «квантовые сенсоры».», фокус в поле; больше 500 — «Сократите запрос до 500 символов.» |
| Ошибка API | баннер «Не удалось создать задание» с текстом сервера |
| Телефон | если форма не помещается на экран, полоса с кнопкой закреплена над нижним меню; тень у полосы — только в закреплённом состоянии (`@container scroll-state`) |

Отправка: `Idempotency-Key` создаётся при открытии формы и меняется после успешной отправки.

## 5. Оболочка

| Элемент | Правило |
|---|---|
| «К содержанию» | первая по Tab, видна только в фокусе (вверху слева, `--brand-fill`, белый текст); переводит фокус в `main` без смены адреса |
| Индикатор API | «API на связи» — два импульса и покой; «API недоступен» — четыре мигания и красная точка |
| «Пауза анимации» | кнопка с `aria-pressed`: на широкой боковой панели — с подписью, иначе круглый значок; выбор хранится в `localStorage` (`ws:motion-paused`) и восстанавливается до первой отрисовки |
| Баннер «API недоступен» | что не работает и что делать — простыми словами; «Для администратора: … `docker compose ps`» — мелким текстом |

## 6. Движение

| Элемент | Когда | Анимация | Длительность | Кривая |
|---|---|---|---|---|
| Страница | открытие | подъём на 10 px и проявление | 0.55 с | `--ease-out` |
| Строки сигналов | появление | подъём, задержка +0.04 с на строку | 0.5 с | `--ease-out` |
| Карточка сигнала | выбор | проявление | 0.45 с | `--ease-out` |
| Шеврон, стрелка меню | раскрытие | поворот на 180° | 0.3 с | `--ease-out` |
| Меню «Экспорт» | открытие | проявление | 0.25 с | `--ease-out` |
| Поле сигналов, пинги, мерцание заглушек | всегда | бесконечные | — | — |

«Пауза анимации» и `prefers-reduced-motion` останавливают бесконечные анимации: развёртка поля
сигналов скрывается, остальное замирает в исходном виде. Анимации появления паузой не трогаются
(при `prefers-reduced-motion` отключаются все).

## 7. Доступность

- **Порядок фокуса:** «К содержанию» → навигация → индикатор и пауза → содержимое в порядке экрана.
  На результатах: шапка → вкладки → список → карточка → сводка.
- **Клавиатура:** вкладки — стрелки влево и вправо; список сигналов — стрелки вверх и вниз, Home,
  End (в списке одна точка табуляции); размер выдачи — стрелки; меню «Экспорт» — Escape;
  строки исключённых и «Фрагмент оригинала» — Enter и пробел.
- **Имена и роли:** вкладки — `role="tab"` с полной подписью (короткая на телефоне скрыта от
  диктора); фильтр исключённых — `aria-pressed`; строки исключённых — `aria-expanded`; пауза —
  `aria-pressed`; ошибка формы — `role="alert"` и `aria-describedby` поля.
- **Язык частей:** `lang` у иноязычных заголовков и фрагментов источников, у оригинальных названий
  и латинских названий кандидатов.
- **Цели нажатия:** на сенсорных экранах (`pointer: coarse`) кнопки, ссылки-кнопки, метки,
  фильтры, вкладки, пункты меню, строки — не меньше 44 px.
- **Контраст:** текст не ниже 4,5 : 1 в обеих темах; `--signal-ink` в светлой теме — #066c7d.

## 8. Крайние случаи

- **Длинный запрос:** до 4 строк в шапке результатов (в приложении — 2), полный текст в `title`.
- **Длинное название технологии:** 2 строки в списке (3 на телефоне), оригинал — 1 строка, в
  карточке — 2; в инсайте без обрезки.
- **Название без скобок или без латиницы в скобках:** выводится целиком, строки оригинала нет.
- **Нет стадии и тренда:** блок фактов не выводится.
- **Нет аналитических отчётов:** в «Оценках» — резюме источников карточки с пояснением; нет и их —
  «Аналитические отчёты по теме среди найденных источников отсутствуют.»
- **Нет фрагмента оригинала:** «Фрагмент оригинала» не выводится.
- **Нет исключённых:** «Ни один кандидат не был исключён.»
- **Нет признаков:** «ключевые предикторы недоступны».
- **Медленная сеть:** скелетоны; опрос задания каждые 3 с, списка заданий — каждые 5 с.
- **`localStorage` недоступен:** пауза работает до перезагрузки.

## 9. Что требует решения в бэкенде

1. В тексте объяснения писать то же число, что на шкале, или оба с подписями
   («индекс 82 %, вероятность классификатора 64 %»).
2. Для признаков `sc_*` отдавать полное слово из профиля, а не основу.
3. Дроби в объяснениях — в процентах или с запятой, как в интерфейсе («0.28» → «28 %»).
