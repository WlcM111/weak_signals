# Отчёт о проверках — сервис ui

Дата: 2026-09-17. Ограничения среды сборки: доступ к реестру npm закрыт (`npm ping` → 403),
Docker и браузер недоступны. Поэтому **сборка фронтенда и визуальная проверка страниц не
выполнялись**; всё, что можно проверить по исходникам, проверено и перечислено ниже.

## Что выполнено

| Проверка | Результат |
|---|---|
| `tools/check_ui_conformance.py` | **PASS**: 8 путей контракта, 33 импорта, 13 модулей, 75 русских строк интерфейса |
| Негативный контроль чекера | подмена `source.summary_kind` **обнаружена**, после отката PASS |
| Разбор TS-модулей (`node --experimental-strip-types`) | `src/lib/format.ts`, `src/api/types.ts`, `src/api/client.ts` — **разбираются и импортируются без ошибок** |
| Корректность JSON конфигурации | `package.json`, `tsconfig*.json` — **валидны** |
| Регрессия остальных компонентов | collector 142, analyzer 191, orchestrator 80 + 28, insight 80, ml 44 — **OK** |
| `check_proto_conformance.py`, `check_sql_conformance.py` | **PASS** |

### Что именно проверяет чекер интерфейса

- каждый путь `docs/api/orchestrator.openapi.yaml` вызывается в `src/api/client.ts`;
- все относительные импорты разрешаются в существующие файлы;
- скобки сбалансированы в каждом модуле (с корректным пропуском строк, регулярных выражений,
  комментариев и закрывающих JSX-тегов);
- компонент источников выводит все восемь полей, которых требует ТЗ: наименование, ссылку, дату
  публикации, тип источника, язык оригинала, уровень доверенности, резюме и его происхождение;
- страница инсайта и Markdown-отчёт содержат все семь обязательных разделов;
- страница результатов показывает счётчики «Кандидатов на слабый сигнал», «Обработано
  источников» и «уверенность выше 75 %»;
- нигде не используется `dangerouslySetInnerHTML` или `innerHTML`;
- в разметке страниц и компонентов нет латинских фраз интерфейса.

## Что НЕ проверялось

| Область | Причина | Как проверить у себя |
|---|---|---|
| Сборка `vite build` и проверка типов `tsc` | реестр npm недоступен (403) | `cd services/ui && npm install && npm run build` |
| Работа страниц в браузере, вёрстка на 1366×768 | нет браузера | `docker compose up -d --build ui` → `http://localhost:8501` |
| Прогрессивная выдача во время `NARRATING` | требует работающего контура | отправить запрос и наблюдать страницу результатов |
| Отмена задания, скачивание отчёта, форма оценки | то же | ручной прогон по чек-листу `HANDOFF_UI §22` |
| Сборка образа `ui` и работа прокси nginx | нет Docker | `docker compose build ui` |

## Известные ограничения

1. Версии зависимостей зафиксированы точными значениями, но `package-lock.json` не
   сгенерирован — первая сборка возьмёт указанные версии из реестра. После неё лок-файл стоит
   закоммитить и перейти на `npm ci`.
2. Дизайн проверялся только по коду: цвета, отступы и типографика заданы токенами CSS, но
   реальный рендер не наблюдался.
3. Скриншоты пяти страниц, которых требует чек-лист `HANDOFF_UI §22`, не приложены по той же
   причине — их нужно сделать при первом запуске стенда.
