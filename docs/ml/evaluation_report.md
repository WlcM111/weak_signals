## 7a. Стилевая отделимость классов (критично для интерпретации метрик)

Длина текста наблюдения: позитивы 126–254 символов (медиана 196), негативы 85–263 (медиана 179).

Контроль ложного признака: модель с единственным признаком «длина текста» даёт accuracy 0.907 на исходных текстах и 0.640 на текстах, поданных в обучение (выравнивание длины: включено). Чем ближе второе число к доле большего класса, тем меньше метрики зависят от стиля авторов.

Опорное решение B1 (TF-IDF по словам, без признаков реестра) даёт F1 0.859. Это означает, что классы различимы по лексике и стилю текста, а не только по содержательным признакам: позитивы написаны методологами заказчика, негативы — командой, и авторский стиль сам по себе является предиктором. Метрики раздела 3 следует читать как верхнюю оценку, не переносимую на скрытую проверку организаторов.

Контрольный прогон «только название» (вариант B схемы обучающей строки, описания удалены у обоих классов, `--text-mode title`): accuracy 0.644, F1 0.500, CV F1 0.630. Разница с основным прогоном показывает вклад описаний (и их стиля) в качество.

Целевая точность кейса — не ниже 80% (граница приёмки 75%). Фактическая accuracy на отложенном тесте — **84.4%**, F1 — **82.9%**. Целевое значение достигнуто на этом наборе данных.

## 9. Ограничения

1. Отрицательный класс размечен командой, а не организаторами: метрики измеряют качество на собственной выборке негативов и не переносятся автоматически на скрытую проверку.
2. Тексты классов написаны разными авторами и различаются длиной и стилем (раздел 7a); до выравнивания описаний негативов по длине и тональности метрики завышены.
3. Эмбеддер `intfloat/multilingual-e5-base`: если это не модель из манифеста analyzer, артефакт предназначен только для офлайн-прогона конвейера.
4. перекрёстная разметка не выполнена: annotation_agreement пуст у всех строк, каппа Коэна не вычислена
5. Коллекционные и энциклопедические признаки вычислены не для всех строк: без доступа к collector они принимают значения «пустой коллекции», и их вклад в модель занижен.
