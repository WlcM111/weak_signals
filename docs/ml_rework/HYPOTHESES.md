# Реестр гипотез и решений

Статусы: **подтверждена** / **не подтверждена** / **недостаточно данных** / **реализовано, проверка на Mac**. Числа — прогон `20260924-hashing-full` (хеширующий эмбеддер, контейнер): семантические признаки v2 в нём ослаблены, поэтому выводы о качестве на e5 требуют прогона на Mac (RUNBOOK_MACOS.md, разд. 9–11).

| ID | Гипотеза | Основание / источник | Решение | Статус и свидетельство |
|---|---|---|---|---|
| H01 | Нерелевантность вызвана экстраполяцией по эмбеддинговым признакам v1 | трассировки `analytics-20260924-003901.txt` | признаки v2: без центроидов; эмбеддинг названия — через замороженную PCA A-train | подтверждена (AUDIT.md, п. 1) |
| H02 | Метка A протекает через текст описания | колонка «Почему это слабый сигнал» в xlsx; TF-IDF F1 0,859 | в признаки A идёт только название | подтверждена; остаточный стиль названия: длина даёт ROC-AUC 0,901 на A-dev |
| H03 | Единица обучения должна совпадать с единицей решения | код run_analysis vs dataset | B размечается на уровне кандидата (кластер + свидетельства) | реализовано; паритет train/runtime покрыт тестом `RuntimeParityTest` |
| H04 | Релевантность теме должна быть признаком модели, а не только фильтром LLM | производственная e5-близость лучше score на dev | `rel_*`, в т.ч. `rel_cluster_query_v1` = e5-близость кластера к запросу | частично: e5-близость dev PR-AUC 0,203 против 0,156 у score; на holdout хуже (0,199 против 0,449) |
| H05 | Знания A (название → «ранняя конкретная технология») переносятся на B без обучения | Mühlroth & Grottke 2018: признаки новизны/конкретности | Stage A zero-shot как базовая линия | недостаточно данных: dev PR-AUC 0,298 (лучший на dev), holdout 0,243 |
| H06 | Тёплый старт без штрафа не сохраняет знания A | выпуклость логистической потери; sklearn `warm_start` — только инициализация | варианты `seq_finetune*` как контроль | подтверждена: сошедшийся fine-tune = b_only (тест), A-dev ROC-AUC 0,67 |
| H07 | Лапласовский штраф (EWC) сохраняет A | Kirkpatrick et al. 2017; Huszár 2018 | `seq_laplace`: α(θ−θ_A)ᵀH_A(θ−θ_A), полный гессиан | подтверждена по забыванию: A-dev 0,917 (Stage A 0,913); прироста на B нет |
| H08 | L2-SP (штраф к θ_A) даёт лучший компромисс | Li et al. 2018 (L2-SP) — по памяти, не перепроверено поиском | `seq_l2sp` | выбран на dev (PR-AUC 0,252, A-dev 0,906), но выигрыша у b_only (0,247) нет в пределах ДИ |
| H09 | Replay только A-train предотвращает забывание без утечки | стандартная практика continual learning | `seq_laplace_replay`, ρ | подтверждена по забыванию (0,910); на dev B 0,213 |
| H10 | Совместное обучение — верхняя граница без ограничений последовательности | — | `joint` как контроль | A-dev 0,917, dev B 0,234 |
| H11 | Состав источников свидетельств (наука/код/медиа) отличает сигналы от шума | EC TIM; Yoon & Kim 2012 (патенты/статьи как ранние индикаторы) | группа `metadata` | не подтверждена на хешировании: без группы dev PR-AUC 0,289 против 0,252 |
| H12 | Порядок LLM подавляет вклад ML | код narrate.apply_judgement | `WS_CANDIDATE_JUDGE_ORDER=ml`: порядок модели, LLM только исключает | реализовано и покрыто тестом; живой эффект — прогон на Mac (разд. 12) |
| H13 | LLM-расширение запроса полезно для ранжирования | признак зависит от расширения | абляция `rel_cluster_query_v1` | на хешировании влияние в пределах шума (0,249 против 0,252) |
| H14 | Больше B улучшит модель | кривая обучения | — | подтверждена для b_only (0,156 → 0,234 при 25 → 100 % групп); кандидат не растёт |
