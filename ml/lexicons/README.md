# Лексиконы

Каталог намеренно пуст: единственный экземпляр лексиконов и правил стадий лежит в
`services/analyzer/config/lexicons/` и `services/analyzer/config/stage_rules.yaml`.

Причина — требование §6.3 задания: признаки обучения и инференса должны считаться одним кодом по
одним и тем же словарям. Копия здесь означала бы два экземпляра, которые неизбежно разойдутся, и
модель начала бы видеть на инференсе не те значения признаков, на которых училась.

Конвейер читает лексиконы по путям из переменных окружения:

```
WS_LEXICON_DIR=/app/services/analyzer/config/lexicons
WS_STAGE_RULES_PATH=/app/services/analyzer/config/stage_rules.yaml
```

Правки лексиконов делаются в каталоге analyzer, после чего модель переобучается: изменение
словаря меняет значения признаков и требует нового `model_version_id`.
