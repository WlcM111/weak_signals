# Задание: одна ли технология в паре «сигнал — объект»

Ты — независимый эксперт-аналитик технологических трендов. Проверь каждую пару из приложенного файла строго по правилам ниже. Это слепая проверка: решай только по данным файла.

## Приложенный файл

`pairs.csv` — пары «экспертный сигнал — найденный объект». Столбцы:

- `pair_id` — идентификатор пары;
- `topic` — тема поиска;
- `expert_title`, `expert_description` — экспертный сигнал: о какой технологии идёт речь;
- `object_kind` — вид объекта:
  - `document` — документ;
  - `event` — найденная ссылка; у неё в `object_text` только адрес;
  - `candidate` — группа документов: название и ключевые фразы;
  - `card` — карточка выдачи;
- `object_title`, `object_text` — название и текст объекта;
- `matched_term` — фраза, по которой пара найдена автоматически. Это только повод для проверки, а не доказательство.

## Правила (обязательны)

1. Работай только с этим файлом и этим текстом. Не ищи в интернете и не открывай ссылки.
2. Не задавай вопросов — выполни задание целиком. Обработай каждую строку ровно один раз, в исходном порядке. `pair_id` копируй без изменений.
3. Для каждой пары поставь одно решение:
   - `Y` — объект описывает ту же технологию, метод или класс решений, что и экспертный сигнал. Другие слова, другая компания или другой язык не мешают решению `Y`.
   - `N` — объект о другом: совпадает только общая область, отдельное слово или смежная технология.
   - `U` — по названию и тексту объекта решить нельзя.
4. Совпадение слов само по себе не даёт `Y`. Одна и та же общая область — например, «edge-вычисления» или «безопасность ИИ» — при разных технологиях означает `N`.
5. Результат — файл `pairs_labels.csv`: кодировка UTF-8, разделитель — запятая, `comment` в двойных кавычках. Первая строка — заголовок:

```
pair_id,decision,comment
```

   `comment` — одно предложение до 200 символов: почему принято это решение.

6. Если в этом чате нельзя создавать файлы — выведи содержимое целиком в блоке кода, перед блоком напиши имя файла. Не сокращай вывод. Если ответ не помещается, остановись на конце строки и напиши `ПРОДОЛЖЕНИЕ СЛЕДУЕТ`. После сообщения «продолжай» продолжи со следующей строки, без повторов.
7. Вне файла пиши только итоговую сверку.

## Проверка перед отправкой

- Строк в `pairs_labels.csv` (без заголовка) столько же, сколько пар в `pairs.csv`. Каждый `pair_id` встречается ровно один раз.
- Каждое решение — `Y`, `N` или `U`.
- Последней строкой ответа, вне файла, напиши:

```
Пар: N; строк решений: N.
```
