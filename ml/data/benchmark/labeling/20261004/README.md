# Разметка двумя моделями, 04.10.2026

Решение владельца проекта: синонимы экспертных сигналов, коды карточек выдачи и решения по спорным парам делают две
внешние модели вместо людей. Каждая работает в новом чате, без контекста проекта, без памяти и без доступа к ответам
другой. Результаты называются «оценка двумя моделями». Требование аудита о двух людях-разметчиках остаётся открытым,
это этап 4.

| Файл | Что это |
|---|---|
| `prompt_round1.md` | запрос 1: синонимы и коды карточек; вложения — `experts.csv`, `cards.csv` |
| `experts.csv` | 100 экспертных сигналов: позитивы `dataset_ds-2026.09.19-v2.jsonl` с темой кейса |
| `cards.csv` | 42 карточки прогона `stand-run-20261004-042021` (шесть тем), без оценок системы; копия из `ml/reports/benchmark/labeling/` |
| `chatgpt_synonyms.jsonl`, `chatgpt_labels.csv` | ответ ChatGPT 6 Astra Max (разметчик 1) |
| `claude_synonyms.jsonl`, `claude_labels.csv` | ответ Claude Fable 5.1 Max (разметчик 2) |
| `prompt_pairs.md` | запрос 2: решения по спорным парам; вложение — `pairs.csv` |
| `chatgpt_pairs.csv`, `claude_pairs.csv` | ответы на запрос 2 (добавляются после второго раунда) |

Объединённые синонимы — `ml/data/benchmark/expert_synonyms.yaml`. Файл собран командой `python -m ml.benchmark
synonyms-merge`; в его шапке записаны SHA-256 ответов моделей.
