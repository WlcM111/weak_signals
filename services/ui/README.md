# ui — аналитическая панель

Web-приложение для аналитика и жюри: открытый запрос, наблюдение за ходом задания, ТОП-15
слабых сигналов со скорингом и ключевыми предикторами, исключённые кандидаты с причинами,
страница-инсайт в виде документа-отчёта, сведения о модели и методология.

**Стек:** React 19 + TypeScript 5.7 + Vite 6, маршрутизация React Router 7, работа с сервером
через TanStack Query 5, собственная дизайн-система на CSS (токены, тёмная и светлая темы).
Собранная статика раздаётся nginx, он же проксирует `/api` на `orchestrator-api`.

## Запуск

```bash
# в составе системы (порт 8501)
docker compose up -d --build ui

# локальная разработка (порт 5173, API берётся из WS_API_BASE_URL)
cd services/ui
npm install
WS_API_BASE_URL=http://127.0.0.1:8080 npm run dev
```

## Страницы

| Маршрут | Назначение |
|---|---|
| `/` | обзор: назначение системы, метрики активной модели, последние задания |
| `/search` | запрос в свободной форме, размер выдачи 1…50, этапы выполнения, последние задания |
| `/results/:jobId` | ход задания, сводка и спектр оценок, ТОП-N, исключённые кандидаты |
| `/insight/:itemId` | документ-отчёт с оглавлением: описание, преимущество, кейс-пример, признаки, источники |
| `/model` | версия и метрики модели, оценка произвольного описания технологии |
| `/methodology` | правила доверенности, правила исключения, группы признаков, ограничения |

## Что показывает интерфейс (требования ТЗ §2)

- поисковый запрос, названия технологий, скоринг модели в процентах;
- ключевые предикторы: до пяти признаков со знаком направления и величиной вклада;
- причины исключения зрелых технологий, хайпа и нерелевантных кандидатов;
- страница инсайта: описание, преимущество, кейс-пример, оценки в аналитических отчётах,
  объяснение статуса, полная таблица 25 признаков, источники, происхождение нарратива;
- для каждого источника — наименование, ссылка, дата публикации, тип, язык оригинала и уровень
  доверенности; резюме иноязычного материала помечено как автоматическое;
- счётчики: кандидатов на слабый сигнал, обработано источников, сигналов с уверенностью > 75 %.

## Внешний вид и адаптивность

Раскладка выбирается по размеру окна. При ширине от 1024 px и высоте от 600 px интерфейс
работает как приложение: слева панель навигации, страница занимает весь экран без общей
прокрутки, длинные списки прокручиваются внутри своих колонок. Результаты собраны на одном
экране: список сигналов, карточка выбранного сигнала, сводка со спектром оценок и журнал
задания. Базовый размер шрифта растёт вместе с окном (14–19 px), поэтому на широких мониторах
интерфейс масштабируется, а не оставляет пустые поля.

В окне меньше страница листается как документ, навигация закреплена сверху; на телефонах
(уже 640 px) навигация переезжает вниз, а подробности сигнала раскрываются прямо в списке.
Внутренние блоки перестраиваются по ширине своей области (`@container`), а не окна.

Светлая и тёмная темы следуют настройке системы, при `prefers-reduced-motion` анимации
отключаются. Шрифты Jura (заголовки и числа) и Lato (текст) лежат в `src/assets/fonts` вместе с
лицензиями OFL и не загружаются со сторонних серверов.

## Взаимодействие с API

Единственный адаптер — `src/api/client.ts`: по одному методу на путь
`docs/api/orchestrator.openapi.yaml`. Таймауты 10 с, для `/api/v1/score` — 100 с.
`Idempotency-Key` (uuid v4) создаётся при открытии формы и обновляется после успешной отправки:
повторное нажатие «Найти» не создаёт второе задание. Пока задание не терминально, состояние и
результат опрашиваются каждые 3 секунды — карточки появляются во время стадии NARRATING без
перезагрузки страницы.

## Безопасность

`WS_API_KEY` подставляет nginx на стороне сервера (`proxy_set_header X-API-Key`), браузер ключ
не получает. Данные выводятся только через React (экранирование по умолчанию): вставки сырого
HTML в коде нет — это проверяет `tools/check_ui_conformance.py`. Ссылки на источники
отображаются как ссылки только при схеме `http` или `https`.

## Конфигурация

| Переменная | Назначение |
|---|---|
| `WS_API_BASE_URL` | адрес orchestrator-api (по умолчанию `http://orchestrator-api:8080`) |
| `WS_API_KEY` | API-ключ, подставляемый nginx в заголовок `X-API-Key` |
| `WS_UI_BIND` | адрес публикации порта 8501 на хосте |

## Проверки

```bash
python tools/check_ui_conformance.py   # пути контракта, импорты, поля источников, русские тексты
cd services/ui && npm run typecheck    # проверка типов (нужен доступ к реестру npm)
```
