## Как интерпретировать

- 429 / GitHub 403 с rate-limit: сервер ограничил запрос. Общий IP, ключ, окно квоты и нагрузку провайдера различает только совокупность данных или поддержка провайдера.
- CERTIFICATE_VERIFY_FAILED: цепочка доверия/CA/перехват TLS. Проверка сертификатов во всех тестах включена.
- Ошибка IPv6 при успешном IPv4: проблема именно доступного IPv6-маршрута либо DNS; не доказательство блокировки API.
- Повторяемая разница Bookworm/Trixie: зависимость от окружения. Один HTTP 406 не доказывает ошибку TLS-рукопожатия: HTTP уже получен.
- 200 + INVALID_XML / NOT_A_FEED / UNEXPECTED_PAYLOAD: транспорт работает, но адаптеру пришёл неподходящий ответ.
- SKIPPED: проверка не выполнена, это не отказ сервиса.
- Tiny generation выполняется только с найденными ключами; списание небольшого числа токенов возможно.
